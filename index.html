Frequently Asked Questions

Can this be hosted on GitHub Pages?

Yes. The entire project is static HTML, CSS and JavaScript, so no PHP server is required.

Does the demo access real WhatsApp messages?

No. It does not connect to WhatsApp, intercept SMS, request OTPs, or obtain session data.

Can the design be customized?

Yes. Logo, colors, text, feature cards, sections and dashboard visuals can all be changed directly in the files.

Does the location page track someone?

No. Any location shown in this frontend prototype is sample data only.

Ready for GitHub Pages

Upload the files to a repository and publish directly from the main branch.
